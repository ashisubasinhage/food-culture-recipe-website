# FoodCulture – Food Culture, Recipes & Cooking Methods

A beginner-friendly front-end web project created with HTML, CSS and JavaScript.

## Features
- Food culture information for 10 countries
- Clickable country cards with individual food-culture pages
- Recipe cards with ingredients and preparation steps
- Cooking-method cards with food examples from different countries
- Recipe and cooking-method search
- Responsive navigation and mobile-friendly layout
- Local `.webp` images stored in the `images` folder

## Technologies
- HTML5
- CSS3
- JavaScript
- WebP images

## Project Structure
- `index.html` – Home page
- `culture.html` – Food Culture page
- `recipes.html` – Recipes page
- `methods.html` – Cooking Methods page
- `images/` – All local project images
- `culture-data.js` – Country food-culture data
- `detail-data.js` – Recipe and cooking-method data
- `styles.css` – Website styling

## Running the Project
Open `index.html` in a web browser, or publish the project with GitHub Pages.
